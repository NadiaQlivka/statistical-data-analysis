# Statistical Data Analysis

Учебная работа по теории вероятностей и математической статистике: исследование выборки из **200 наблюдений**, расчёт статистических характеристик и проверка гипотез.

## Что выполнено

- Построены вариационный ряд и интервальное распределение частот, графики статистического распределения.
- Рассчитаны среднее, медиана, дисперсия, стандартное отклонение, асимметрия и эксцесс.
- Получены точечные оценки и доверительные интервалы для параметров распределения.
- Проверены статистические гипотезы с помощью критерия **χ²**, критериев **знаков** и **Вилкоксона**, критерия **Колмогорова — Смирнова**.
- Сформулированы выводы по результатам расчётов.

## Инструменты

Excel; Python (Pandas, NumPy, SciPy) — для дополнительных вычислений.
